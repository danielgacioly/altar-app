Lembra no meio do dia, não no meio do sono.

Cansado de falhar na constância devocional? Conheça o Altar, um app de Mac que lembra você do devocional enquanto o dia acontece (disparando notificações quando percebe um certo tempo de atividade no computador) e guarda uma página para você registrar o que Deus falou com você em cada dia.

Notas por voz

A transcrição acontece no próprio Mac, em português, sem enviar o áudio para lugar nenhum.

Plantas

Uma árvore para cada mês do ano.

Cada devocional faz a planta do mês crescer. Quando o mês acaba, ela é colhida do tamanho que chegou. Os meses que ainda não vieram esperam em preto e branco.

Privacidade

Fica entre você e Deus.

Sem conta na internet

Sua conta é só um nome e uma foto guardados no seu Mac.

Sem nuvem

Páginas, notas e orações ficam numa pasta do seu computador.

Backup quando quiser

Exporte tudo num arquivo e restaure em outro Mac.

Instalar

Pronto em um minuto.

  1. Baixe o Altar e arraste para a pasta Aplicativos.
  2. Abra o app. Ele pede permissão para notificações e passa a abrir junto com o login.
  3. Em Ajustes do Sistema > Notificações > Altar, escolha Alertas, para o lembrete ficar na tela até você responder.

Ou compile a partir do código, com o Xcode 26:

git clone https://github.com/danielgacioly/altar-app
cd altar-app
xcodebuild -project Altar.xcodeproj -scheme Altar \
  -configuration Release -derivedDataPath build build
cp -R build/Build/Products/Release/Altar.app /Applications/
